# 猫娘广告部 v0.1.0

用户主动开局的广告整蛊小游戏。古早页游海报、角落弹窗、假含猫量体检和插件推荐，搭配猫娘文字、表情与可选系统日语朗读。宣传仅限猫娘计划和实时市场返回的真实插件。

## 版本状态与下一步要求（2026-10-19）

当前代码暂定为 **v0.1.0 原型**，尚未发布正式版本。以下桌宠集成要求已经确认，本轮仅记录，不实现，也不将它们标为已完成：

- **接入桌宠主界面**：开局后，广告直接出现在用户正在使用的桌宠主界面中，制造被广告打扰的感觉。独立游戏页仅作为现有原型，不是最终体验。
- **由当前猫娘反馈**：使用用户当前选择的猫娘及宿主的表情、气泡和语音能力，针对关闭失败、成功关窗、查看推荐等行为作出雌小鬼风格的戏谑反馈。游戏页内的占位猫娘和系统朗读不能替代这项集成。
- **保留可靠安全词退出**：真实安全词与备用退出通道位于宿主控制层，不依赖模型识别或回复，不参与广告整蛊，不受广告遮挡或焦点劫持影响。触发后应立即清理所有广告、插件触发的语音和排队事件，旧回调不能复活本局；刷新、重启不自动续局。
- **维持最简开局说明**：只明确安全词及实际可用的退出快捷键，用户确认后开局，不预告广告关闭机关。
- **内容与玩法延续当前方案**：参考 dsh-ads 的古早流氓广告体验；内容只宣传猫娘计划和真实市场插件，标题可以夸张，但不能虚构插件功能。保留假叉、躲避、赠送广告、假体检与猫娘吃瘪等互动。
- **账号约束**：不新增 GitHub 账号绑定、登录或授权流程；插件运行及游戏退出不以 GitHub 账号为前提。

桌宠版还需验证：主界面焦点变化、中文输入法、重复退出、退出与开局并发、插件停用/崩溃/失联、切换当前猫娘、模型或语音仍在处理时退出。当前原型的页面快捷键与切换标签自动退出策略需要按宿主实际能力调整，不能直接宣称已支持全局热键。

## 使用

目录与其他插件并列：`plugin/plugins/neko_ads/`。在插件管理器刷新列表、启动「猫娘广告部」，打开插件面板，阅读退出说明并点击「确认，开始游戏」。也可以在插件服务地址打开 `/plugin/neko_ads/ui/`。

本版广告显示在独立插件游戏页内，不会覆盖操作系统或桌宠主界面；猫娘反馈是游戏页内的猫娘表情和气泡，不接管当前桌宠的对话模型或语音。页面的聊天框是小游戏输入，不是模型聊天。无需新增依赖或前端构建。

这是独立插件仓库，运行与 Python 测试需要 N.E.K.O 宿主及其 SDK；不是可独立启动的桌宠应用。开发时将仓库放在宿主的 `plugin/plugins/neko_ads/`，以下测试命令从宿主项目根目录执行。插件及小游戏无需用户绑定 GitHub 账号，市场不可用也可以开局。

## 真正退出

- 在游戏页下方输入「广告下班」，无需按发送；支持粘贴与中文输入法提交。
- 游戏页有焦点时按 `Ctrl + Shift + Q`。这是页面快捷键，不是操作系统全局热键。
- 离开页面、切换到其他标签页、断网会自动结束。
- 插件面板暴露 `stop_game`（立即结束）动作。不传 `round_id` 可结束当前局。

退出先在本地清除所有广告、计时器和语音，再尽力通知后端。后端不可达也能本地退出；存活检查失败后自动退出，正常前台约 3.5 秒内检测到插件停止。服务器会话 8 秒无心跳即失效，下次心跳不能复活。冻结和停止插件立即退休服务器会话。刷新或重新打开页面不会续局，必须重新确认。突然关闭页面导致退出通知未到达时，旧租约最多 8 秒后释放。

## 玩法

最多同时三张广告；假叉需再关一次、会跑的叉最多逃两次、假体检先显示结果、市场广告关掉后赠送下一张。广告里的机关属于游戏。真实出口不参与整蛊，不会播放退出后的嘲讽。

文字反馈与表情即时更新；日语朗读使用系统提供的日语语音，并非角色配音或预录语音包。没有日语语音时只显示文字。朗读同一时间只播一句，语音有冷却，退出取消队列。本版没有随包提供第三方语音素材。

实时插件推荐走宿主现有的只读市场桥接，不安装插件，不使用令牌、不读写用户文件。市场不可用则只展示猫娘计划宣传。插件功能描述使用市场原文，夸张标题属于戏仿。链接仅在点击后打开。

## 开发与验证

- Python 入口仅导入 `plugin.sdk.plugin` 公开 SDK；`plugin.toml` 显式声明静态面板与动作权限。
- `session.py` 管理短期会话、退出墓碑和锁；不持久化运行状态。
- `static/engine.js` 是可单独测试的游戏状态机；`main.js` 负责 DOM、退出监听、语音和宿主动作桥接。
- `python -m pytest plugin/plugins/neko_ads/tests/test_session.py`
- `node --test plugin/plugins/neko_ads/tests/engine.test.cjs`
- 浏览器回归：`node plugin/plugins/neko_ads/tests/browser.cjs`（复用项目 `frontend/plugin-manager` 的 Playwright，仅使用本地假宿主验证，不启动真实猫娘或市场）。
