# 猫娘广告部 v0.1.0

N.E.K.O 广告整蛊插件，以古早页游海报、弹窗和假体检宣传猫娘计划，并推荐真实市场插件。用户主动开局，可随时通过安全词退出。

## 当前功能

v0.1.0 为独立游戏页原型，目前包含：

- 四类广告：页游海报、角落弹窗、含猫量体检、插件推荐。
- 假关闭、按钮躲避、关闭后赠送等交互，同时最多显示三张广告。
- 猫娘表情和嘲讽文字，根据用户操作即时反馈。
- 可选系统日语朗读；未安装日语语音时使用文字反馈。
- 安全词退出、页面快捷键、失联自动结束，刷新不续局。

当前广告和猫娘反馈仅显示在插件游戏页内，尚未接入桌宠主界面或当前角色。日语朗读使用系统语音，不包含角色原声包。

广告内容只宣传猫娘计划与真实市场插件。插件描述取自市场，夸张标题属于戏仿；市场不可用时只展示猫娘计划宣传。链接由用户点击打开，不自动安装插件。

## 使用

需要 N.E.K.O 宿主及其插件 SDK，无需额外前端构建。

1. 将插件放入宿主的 `plugin/plugins/neko_ads/`。
2. 在插件管理器刷新列表，启动「猫娘广告部」并打开面板。
3. 阅读安全词与退出快捷键说明，点击「确认，开始游戏」。

游戏页也可通过插件服务的 `/plugin/neko_ads/ui/` 访问。页面聊天框用于小游戏交互，不调用对话模型。

## 退出

- 在游戏页下方输入安全词 **广告下班**，无需发送；支持粘贴和中文输入法提交。
- 游戏页有焦点时按 **Ctrl + Shift + Q**。此快捷键仅在页面内有效。
- 离开游戏页、切换标签页或断网会自动结束。
- 插件提供 `stop_game` 动作；不传 `round_id` 可结束当前局。

安全词退出先在本地清理广告、计时器和语音，再通知后端，不依赖模型或网络响应。插件停止由存活检查检测；正常前台约 3.5 秒内自动结束。后端会话 8 秒无心跳即失效，延迟请求不能恢复已结束的游戏。

## 后续规划

- **桌宠主界面广告**：广告直接出现在用户正在使用的桌宠界面中，独立游戏页保留为原型。
- **当前角色反馈**：接入当前猫娘的表情、气泡与语音，根据关窗和查看推荐等行为作出戏谑反馈。
- **宿主级退出**：安全词与备用退出通道由宿主直接处理，不依赖模型、不受广告遮挡。退出同时清理浮层、插件触发的语音与排队事件，刷新或重启不自动续局。
- **开局说明**：仅告知安全词及实际可用的退出快捷键，用户确认后开始，不提前揭露广告机关。

桌宠集成需覆盖焦点变化、中文输入法、切换角色、插件异常，以及语音或模型处理期间的退出。以上功能尚未实现。

## 开发与验证

- `plugin.toml`：SDK 版本、静态面板和动作权限。
- `session.py`：会话、心跳与退出状态。
- `static/engine.js`：游戏状态机；`static/main.js`：界面、语音和宿主桥接。

在宿主项目根目录运行：

```text
python -m pytest plugin/plugins/neko_ads/tests/test_session.py
node --test plugin/plugins/neko_ads/tests/engine.test.cjs
node plugin/plugins/neko_ads/tests/browser.cjs
```

浏览器测试复用宿主 `frontend/plugin-manager` 的 Playwright，使用模拟宿主验证交互和退出，不连接真实插件市场。
